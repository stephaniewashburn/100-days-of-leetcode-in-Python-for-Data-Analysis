# 100-days-of-leetcode-in-R
Hi there!
I will be reviewing topics in Python through a 100 day leetcode challenge!

Each day contains a short LeetCode-style data analysis problem designed to reinforce both foundational and advanced Python skills through repeated retrieval practice. 

## Goal

Complete 100 data analysis problems in Python while progressively reducing reliance on external assistance and strengthening my ability to write analysis code from memory.

## Topics

Topics covered throughout the challenge include:

- Data manipulation with pandas
- NumPy and numerical computing
- Data cleaning and preprocessing
- Filtering, sorting, grouping, and aggregation
- Missing data
- Merging and joining datasets
- Reshaping data
- Data visualization with Matplotlib and Seaborn
- Exploratory data analysis
- Functions, loops, and Python fundamentals for data analysis
- Feature engineering
- Statistical analysis
- Regression and classification
- Machine learning with scikit-learn
- Model training, validation, and evaluation
- Cross-validation and hyperparameter tuning
- Clustering and unsupervised learning
- Longitudinal and behavioral data analysis
- End-to-end data science workflows
